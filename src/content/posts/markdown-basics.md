## 标题与列表

使用 `##` 写小标题，用 `-` 写列表：

- 一个知识点
- 一个待解决的问题
- 一个接下来要做的小练习

## 代码和链接

用反引号标出行内代码，例如 `npm run dev`。代码较长时可以使用代码块：

```js
const message = "今天也学到了一点新东西";
console.log(message);
```

也可以添加 [Markdown 基本语法](https://www.markdownguide.org/basic-syntax/) 链接，方便回到有用的资料。
